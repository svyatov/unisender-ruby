# Security policy

## Supported versions

Security fixes target the latest published release. Upgrade to that release before reporting a problem when possible.

## Report a vulnerability

Email [Leonid Svyatov](mailto:leonid@svyatov.com) privately. Expect an initial response within seven days.

Include the affected gem and Ruby versions, the security impact, and a minimal reproduction using fake credentials and contact data. Do not include live API keys, recipient data, or account exports. Do not disclose the vulnerability in a public issue before a fix or coordinated disclosure date is agreed.

The maintainer will assess the report and coordinate a fix and disclosure with you.
